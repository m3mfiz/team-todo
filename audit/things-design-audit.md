# Аудит дизайна Things 3 (Cultured Code) — что переносим в team-todo

Дата: 2026-06-12. Цель — зафиксировать визуальный и UX-язык Things,
чтобы клиент team-todo ощущался «как Things», оставаясь командным.

## 1. Визуальный язык

- **Фон**: чистый белый/почти белый (#FFFFFF / #F7F7F7 для группировок).
  Никаких теней-карточек у каждой задачи — задачи это строки списка.
- **Акцентный цвет**: фирменный синий (#3B82F6-подобный; у Things ≈ #4A90D9)
  только для интерактивных элементов: чекбоксы при наведении, кнопки,
  активный пункт навигации, заголовок «Сегодня» — жёлтая звезда.
- **Чекбокс**: круглый, тонкая серая обводка; при отметке заливается синим
  с белой галочкой и короткой анимацией, задача плавно уходит из списка
  (в Журнал) с задержкой ~1.5s — даёт шанс отменить.
- **Типографика**: системный шрифт (SF Pro / -apple-system), крупные жирные
  заголовки разделов (28–34px), задачи — 15–17px regular, заметки — 13px
  серым (#8E8E93).
- **Отступы**: щедрые. Список не плотный: высота строки ~44px+, поля 16–20px.
- **Иконки разделов** (цветовой код Things):
  - Сегодня — жёлтая звезда ★
  - Предстоящие — красный календарь
  - Все задачи (Anytime) — бирюзовые слои
  - Журнал — зелёная галочка

## 2. Структура и навигация

- Разделы-списки: Inbox, **Today**, **Upcoming**, **Anytime**, Someday,
  **Logbook**. Для team-todo берём 4: Сегодня / Предстоящие / Все задачи /
  Журнал (Inbox и Someday избыточны для командных задач).
- На телефоне — навигация снизу/списком, один уровень вглубь; на десктопе —
  сайдбар. Мы делаем mobile-first: нижняя панель вкладок.
- **Upcoming** группирует по датам: ближайшие дни заголовками, дальше — по
  месяцам. Просроченное поднимается в «Сегодня» с красной пометкой.

## 3. Взаимодействия

- **Кнопка «+»**: плавающая круглая синяя внизу справа — главный жест
  добавления. Быстрый ввод: заголовок, заметки, дедлайн; сохранение по Enter.
- Тап по задаче раскрывает её на месте (inline-редактирование) — не отдельный
  экран. Поля: заголовок, заметки, дедлайн, (для админа) исполнитель.
- Свайпы в Things (перенос даты) на вебе заменяем явными контролами.
- Пустые состояния — дружелюбные: «Всё сделано» с лёгкой иллюстрацией/эмодзи.

## 4. Адаптация под командный сценарий (отличия от Things)

Things — однопользовательский. Добавляем минимально-инвазивно:

- Бейдж **«Всем»** на общих задачах (assignee = все).
- В админ-режиме под заголовком задачи — серым имя исполнителя.
- Селектор исполнителя в форме добавления — только у администратора.
- Логин-экран в том же языке: белый, по центру, синяя кнопка.

- [ ] 4 раздела с цветными иконками Things-кода
